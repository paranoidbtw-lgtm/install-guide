Installation Guide

Follow this guide to install the loader, configure your system, and troubleshoot common issues.

Prerequisites

  • Install the required Microsoft Visual C++ Redistributable
  • Restart your PC after installation
  • Disable Intel Rapid Storage Technology (RST) in BIOS, if required
  • Disable Secure Boot, if required by your product
  • Confirm virtualization settings match the loader's requirements
  • Read all instructions before launching the loader

Installation

1

Download the Loader

Download the loader using the link provided on your product page.

2

Run the Loader

  1. Locate the downloaded file
  2. Right-click the file
  3. Select Run as administrator
3

Update the Loader

  1. Allow the loader to check for updates
  2. Wait for the update process to finish
  3. If prompted, close and reopen the loader
4

Enter Your License Key

  1. Enter your license key in the designated field
  2. Press Enter to continue
5

Launch the Game

  1. Follow the loader's on-screen instructions
  2. Wait for initialization to complete
  3. Launch your game if instructed
  4. Avoid switching windows during initialization
6

Open the Menu

Wait approximately 1–2 minutes for initialization, then use the hotkeys below.

KeyFunction
HOME / INSERT Open or close the menu

Troubleshooting

🔧 Troubleshooting — Common Errors

PIN / Hyper-V Error

Please make sure PIN is not set and manually disable Hyper-V.
  1. Check the product's official compatibility instructions
  2. Review your Windows Security, Windows Hello PIN, and Hyper-V configuration
  3. Restart your PC after making any configuration changes
  4. Do not delete or modify Windows hypervisor system files manually
  5. If the error persists, contact support with your Windows version and loader version

Failed to Map Memory

Possible causes: insufficient RAM, conflicting startup applications, or incompatible system configuration.

  1. Check the product's minimum RAM requirements
  2. Restart your PC
  3. Close unnecessary applications
  4. If support recommends Microsoft Sysinternals Autoruns, use it to identify conflicting startup apps — do not disable entries indiscriminately
  5. If the issue persists, collect the error message and contact support

Loader Closes Without an Error

Possible causes: missing software dependencies, incomplete installation, or a compatibility issue.

  1. Install the required dependencies listed in the official product documentation
  2. Restart your PC
  3. Run the loader again
  4. If the issue continues, send support the loader version and any available logs

Menu Is Visible but Not Clickable

  1. Confirm the overlay is enabled for the correct game
  2. Check the overlay's documented permission requirements
  3. Close other overlays that may conflict
  4. Restart the game and the overlay
  5. If the issue persists, contact support

Windows Antivirus Errors

Security software may flag unfamiliar executables. An alert does not automatically mean the file is safe or unsafe.

  1. Verify the download came from the official source
  2. Check the file's digital signature and scan results
  3. Review the antivirus detection name and submit a false-positive report if appropriate
  4. Contact support if the file is blocked
  5. Do not disable Windows Defender or SmartScreen globally to bypass an alert

AES Instruction Set Not Supported

Your processor does not support a required AES instruction set.

  1. Check your processor model against the product's minimum CPU requirements
  2. Confirm the error with support
  3. If your hardware is unsupported, ask about refund eligibility
Note A software update cannot add CPU instructions the processor does not physically support.

BIOS Configuration Errors

Intel Virtualization

Look for Intel Virtualization Technology (VT-x) in your BIOS.

AMD Virtualization

Look for SVM Mode or AMD-V in your BIOS.

Secure Boot

Check the official product requirements before enabling or disabling Secure Boot.

Note BIOS menu names vary by manufacturer. Consult your motherboard or PC manufacturer's documentation if you cannot find a setting.

Unsupported Firmware

The current boot configuration or disk partition format may be unsupported.

  1. Check whether your Windows system disk uses MBR or GPT
  2. Back up important files
  3. Review Microsoft's official documentation for the MBR2GPT tool
  4. Verify your system meets the required UEFI boot configuration before converting
Warning Do not convert your system disk without a backup and a clear understanding of the recovery process.

Secure Boot Keys Incorrect

A Secure Boot configuration or key issue.

  1. Check your motherboard manufacturer's Secure Boot documentation
  2. Verify the current Secure Boot configuration
  3. Follow the manufacturer's recovery instructions if the keys are incorrect
  4. Contact support if the error continues
Warning Changing Secure Boot keys or restoring factory keys can affect your boot configuration. Do not reset them without confirming the correct procedure for your device.

VMX / SVM Not Supported

A virtualization configuration or compatibility issue.

  1. Check whether your CPU supports Intel VT-x or AMD-V
  2. Review the product's official Windows virtualization requirements
  3. Check whether Hyper-V or Virtual Machine Platform is conflicting
  4. Restart your PC after any configuration changes
  5. If the error persists, provide support with the exact error message and your Windows version

Incorrect HWID

May result from a hardware change, identification issue, or licensing configuration problem.

To collect hardware information, open Command Prompt and run:

wmic diskdrive get Caption, SerialNumber
wmic baseboard get SerialNumber

If wmic is unavailable, use Windows System Information or PowerShell. Share the results privately with official support.

Note Do not reinstall Windows solely because these commands fail. Reinstallation is unlikely to fix a simple command or licensing error.

Still Need Help?

If you are still experiencing issues, open a support ticket and include:

  • Your exact error message
  • Your Windows version
  • Your CPU model
  • Troubleshooting steps you've already tried
  • Screenshots or logs, if available

Providing these details helps the support team diagnose the problem faster.
